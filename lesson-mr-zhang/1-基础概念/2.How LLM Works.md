   A bana is

Prompt --> Fine-tuned & RLHF Model --> Response
user prompt:

Note the differences between the two above.
First model is just a document completer where it will only complete the prompt with what it finds with the highest possibility to become the next character. This is the model which we trained on the chunk of internet data,it's called the base model.

The second model is a document generator where it will generate a response more like a human based on the prompt question. This is the ChatGPT model.

The ChatGPT model is an inference model that can generate a response based on the prompt question. i'll say its 99% the base model, but with two extra steps of training: A fine-tuning step and a reinforcement learning from human feed back step

Pre-training: Base Model
This constitutes the very core of the AI revolution and is where the magic truly lies.
Training as model is a process of feeding it with a lot of data and let it leran from it. As described in the GPT-3 paper, the base model is trained on a large chunk of internet data. That's not an easy task for any individuals like you and me. It not only requires obtaining the data,but also requires a lot of computing power like GPU and TPU.

The innovation behind LLM training lies in the introduction of the Transformer architeure, which enabled the model to learn from vast quantities of data while preserving crucial contextual relationships between different parts of the input.
By maintaining these connections,the model can effectively infer new insights based on the provided contexts,whether they be individual words,sentences,paragraphs,or beyond.With this captbility,LLM training has opend up new opportunities for natural language

Fine-tuning:Train the Assistant
Fine-tuning is a very smart implementation. I guess it's first done by OpenAI. THe idea is super simple but works intelligently: hire huamn labelers to create lots of Q&A conversation pairs(like 100k conversations). Then feed the model with the conversation pairs and let it learn from it.
This process is called Fine-tuning. YOu know what happens after those 100k sample conversations are trained into the model ? THe model will start response like a human!
Let's take a look at those sample labeled conversations:
Human labeled Q&A
Q:what is you name ?
A:My name is John


these sample Q&A are mocking the way we talk to each other. By taching the model these respond styles,the probatility of the releated contextual response will become very high and become response to a user's prompt. Through training the model in various converstational styles, we increase the likelihood that it will provide relevant and contextual appropriate responses to prompts.

At this step, we can say we obtained an Assistant Model.


RLHF: reinforcement Learning from Human feedback
这一步骤是根据人类反馈，对fine-tuning model继续迭代优化的一个方法，根据大众的反馈让他update自己的model参数。其实也就是相当于之前fine-tuning只小范围自己问答，帮助他形成人类回答的能力，现在这个RLHF是帮助他实际为人类服务，帮助他从全人类的真实回答和反馈中更好的训练他的数据集

Here is a base model vs fine-tuned/RLHF response comparison:
prompt: Explain the moon landing to a 6 year old in a few sentences.
Base Model: Explain the theory of gravity to a 6 year old.Explain the big bang theory to a 6 year old.

Fine-tuned/RLHF: People went to the moon, and they took pictures of what they saw, and setn them back to the earch so we could all see them.
YOu can see without find-tun and RLHF , the model is just a document completer


Prompt Engineering
Even with the fine-tuning and RLHF, the model still needs some help to get the desired response, And this is where the prompt engineering comes in.
In simple words, we can carefully design the prompt to get the desired response from the model(sometimes even without fine-tuning)
if you are not trying to dive too much into the mathematics and code, then prompt engineering is the good way to pay more attention, because it can get the best out of an LLM model simply by typing a better prompt

提示词工程师就是用提示词引导LLM，也可以理解为对LLM做特定的训练吧，
比如我6岁的时候我弟弟是我的岁数的1半， 我20岁的时候，我弟弟多大？ gpt就可能打错，理解为10岁。
