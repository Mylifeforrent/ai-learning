# 课件需求简报

## 核心目标
让中级开发者从"会存取记忆"升维到"懂窗口策展"，掌握 Agent 上下文工程的完整分析框架（六模块坐标系 + Anthropic 五策略），并建立场景选型和成本优化的工程师直觉。

## 受众画像
- 技术背景：中级开发者，已完成 Agent 长短期记忆管理课程（含 mem0 实战），熟悉 mini-OpenClaw 项目结构，具备 Python 中级能力和 LangChain 基本概念
- 使用场景：大屏投影（授课现场）+ 个人电脑（自学）+ 录屏回放（异步学习）

## 视觉风格倾向
- 风格类型：P03 梦幻柔光（浅色主题，柔和渐变，专业但不沉重）
- 配色：Split-complementary (blue + warm sand)，primary #2D5A7A / accent #c17f59
- 字体：Sora / Noto Sans SC
- 动效：medium level

## 交互密度预期
偏轻交互为主，两个重交互页面（六模块全景图、五策略全景图），其余以卡片展开、数据对比、流程图为主

## 硬性禁止项
无

## 用户期望感受
「终于搞清楚了，之前一直没想明白」+ 「好想动手试试，感觉能做出来」

## 课程时长
90 分钟，4 章 28 页

## 源材料
- lesson.md（1314行，完整 Jupyter 课件内容）
- 01-concept-map.md（概念图，7 个核心概念 + 关联关系）
- 02-process-notes.md（深度加工笔记，3 个"为什么"的四层分析）
